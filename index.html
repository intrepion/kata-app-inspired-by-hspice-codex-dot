THE FIELDBOOK

Follow the signal.

Voltbench is an independent educational workbench inspired by HSPICE’s netlist → analysis → waveform workflow. It does not use HSPICE or claim HSPICE compatibility.

  1. Choose an example, or open a plain-text .sp netlist.
  2. Edit passive component values or switch to the netlist editor.
  3. Pick an analysis and press Run simulation.
  4. Toggle traces, inspect points, or export CSV and your project.

The supported subset

Ideal R, C, L and independent voltage/current sources. DC, AC, SIN and PULSE sources. .op, .dc, .ac dec and .tran directives. Ground is node 0. SI suffixes include k, meg, m, u, n and p: 1m is 0.001; 1meg is 1,000,000.

Know the limits

No diodes, transistors, semiconductor models, subcircuits, .param, noise, temperature, process corners, optimization or signoff verification. A small JavaScript linear solver uses fixed-step backward Euler for transients, which can damp oscillation. Tighten the time step to check numerical sensitivity. Maximum 30 nodes, 80 parts and 2,500 output points. Unsupported syntax is rejected.

Projects autosave locally when browser storage is available. Export important work; clearing site data removes the local copy. Imported files stay on your device.
